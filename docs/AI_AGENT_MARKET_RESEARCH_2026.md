### 3.2 Detalle por Proveedor

#### Pinecone
- **Serverless**: Pay-per-request, ideal para workloads impredecibles
- **Dedicated Read Nodes**: Para workloads de alto QPS, pricing por hora por nodo
- **Standard**: $50/mes minimo, incluye $15/mes en creditos
- **Enterprise**: $500/mes minimo
- **Fortaleza**: Lider de mercado, serverless maduro, facil de usar
- **Debilidad**: Costoso a escala, vendor lock-in, sin self-hosting

#### Weaviate
- **Shared Cloud**: Desde $25/mes, pay-as-you-go
- **Enterprise Cloud**: Desde $10,000/anio (AWS/Azure Marketplace)
- **Pricing**: ~$0.095/1M vector dimensions (Standard), $0.285/1M (Enterprise)
- **Fortaleza**: Hybrid search (dense + BM25), modular, multi-tenancy
- **Debilidad**: Costoso en enterprise, pricing complejo

#### Qdrant
- **Cloud**: 1GB gratis, luego $0.014/hora (Hybrid Cloud)
- **Premium**: 24/7 support, 99.9% SLA, SSO, VPC
- **Fortaleza**: Open source (Apache 2.0), performance excelente, self-hosted viable
- **Debilidad**: Menos integraciones que Pinecone, requiere gestion de clusters

#### ChromaDB
- **Open Source**: Apache 2.0, gratis
- **Cloud**: $5 creditos gratis, luego $100 creditos usage-based
- **Fortaleza**: Ultra-ligero, ideal para prototipado, embebible
- **Debilidad**: No production-ready para alto volumen, features limitadas

#### pgvector (PostgreSQL)
- **Costo**: $0 adicional (extension de PostgreSQL existente)
- **Performance**: pgvector 0.8.0 con mejoras de 5.7x vs version anterior
